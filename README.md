RPG Character Creator AI

An AI-powered RPG character generator built with Python, Streamlit, and Google Gemini API.

Users can generate fantasy RPG characters with:

classes
abilities
weapons
strengths
weaknesses
pets
backstories

The app displays generated characters inside a stylized RPG card UI.

Features

AI-generated RPG characters
Streamlit web app interface
Gemini AI integration
Custom prompt engineering
Styled RPG character cards
Character roles and abilities
Pet and companion system
Structured AI output formatting

Technologies Used

Python - Main programming language
Streamlit	- Web app framework
Gemini API - AI character generation
HTML/CSS - Custom RPG card styling
Git & GitHub - Version control
